# kepano/obsidian-skills — Source Summary

**Summary**: A collection of agent skills that teach LLM coding agents (Claude Code, Codex CLI, OpenCode) how to work with Obsidian-specific formats: Obsidian Flavored Markdown, Bases (.base), JSON Canvas (.canvas), Obsidian CLI, and web page extraction via Defuddle.

**Key Takeaways**:

1. **5 discrete skills**: obsidian-markdown, obsidian-bases, json-canvas, obsidian-cli, defuddle
2. **Multi-agent compatibility**: Works with Claude Code, Codex CLI, OpenCode — follows the Agent Skills specification
3. **Domain-specific**: Teaches agents Obsidian-specific syntax (wikilinks, embeds, callouts, properties) not just generic coding
4. **Defuddle integration**: Clean markdown extraction from web pages, removes clutter to save tokens
5. **3 install methods**: Marketplace plugin, npx skills, manual copy
