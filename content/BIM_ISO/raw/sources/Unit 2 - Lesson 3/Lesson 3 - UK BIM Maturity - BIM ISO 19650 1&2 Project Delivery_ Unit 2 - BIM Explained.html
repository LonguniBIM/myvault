UK BIM Maturity

00:41

BIM Level 0

This is no longer recognised within the latest BIM Stages. BIM Level 0 represented unmanaged CAD probably 2D, with paper or PDF as the most likely data exchange mechanism.

00:25

BIM Stage 1

Object Based Modelling

Managed CAD in 2D or 3D format using a CDE and possibly some standard data structures and formats. 

00:48

BIM Stage 2

Model based Federation & Collaboration

Managed CAD in 2D or 3D format using a CDE and possibly some standard data structures and formats. 

01:15

BIM Stage 3

Integrated Servers

BIM Stage 3 is still under development, however its purpose is for whole lifecycle management of the assets, and server based models represent a change in how we share information.
