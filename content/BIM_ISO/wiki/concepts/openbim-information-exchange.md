# OpenBIM Information Exchange & COBie

Under **ISO 19650-4**, information exchanges should leverage open, vendor-neutral data schemas to ensure longevity, multi-disciplinary accessibility, and freedom from proprietary software lock-in.

## Key Open Standards
1. **Industry Foundation Classes (IFC - ISO 16739)**: Object-based 3D data model representing geometry, spatial hierarchy, and relationships.
2. **COBie (BS 1192-4 / buildingSMART)**: Construction Operations Building information exchange, capturing alphanumeric maintainable asset data (spaces, equipment, serial numbers, warranties) delivered via spreadsheet or XML.
3. **BIM Collaboration Format (BCF)**: XML / REST protocol for exchanging coordination issues and clash viewpoints without transmitting entire models.
4. **Uniclass 2015**: Unified classification system structuring assets, systems, and elements across the UK and international projects.
