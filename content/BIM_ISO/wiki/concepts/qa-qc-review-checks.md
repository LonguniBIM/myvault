# Quality Assurance & Quality Control (QA/QC) Review Checks

## Core Concept
Under ISO 19650-2 clause 5.6.2, every task team must conduct rigorous internal verification of information containers before submitting them for sharing, ensuring that only coordinated, compliant data enters the multidisciplinary shared environment.

## Three Tiers of QA/QC Checks
1. **Technical Content Checks**: Engineering calculations, dimensional accuracy, code compliance, and buildability.
2. **BIM Standards & Syntax Checks**: Container naming, layer conventions, Uniclass classification, and parameter completeness.
3. **Spatial Coordination & Clash Checks**: Internal collision detection between elements and against recent Shared reference models.
