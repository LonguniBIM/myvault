# Security-Minded Approach to Information Management

Under **ISO 19650-5**, a security-minded approach balances transparent collaboration with the imperative to protect sensitive built assets from hostile reconnaissance, cyber disruption, terrorism, or intellectual property theft.

## The Security Triage Process
Before information is shared, the appointing party executes a triage evaluation:
1. *Does the project involve critical national infrastructure, hazardous facilities, or high-profile public assets?*
2. *Does the information include sensitive layout data (CCTV networks, high-voltage power feeds, secure access systems, executive suites)?*
3. *If YES*: Formally trigger ISO 19650-5 compliance, appoint a Security Manager, and mandate a Security Management Plan.
4. *If NO*: Standard ISO 19650-2 collaborative CDE procedures apply.
