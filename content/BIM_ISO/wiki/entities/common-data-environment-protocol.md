# Common Data Environment Protocol (Information Protocol)

The **Common Data Environment Protocol** (often implemented via the Project Information Protocol under ISO 19650-2 §5.1.8) establishes the legal, contractual, and technical obligations governing information sharing via the project Common Data Environment (CDE).

## Purpose & Incorporation
- The Information Protocol must be incorporated into every appointment across the project.
- It translates ISO 19650 processes into legally binding commitments.

## Key Clauses & Governance
1. **Status Code Reliance**: Defines what rights parties have to rely on information containers based on their assigned CDE status code (e.g. S1 for Coordination vs. A1 for Construction).
2. **Intellectual Property (IP)**: Ownership and licensing rights of BIM models and documentation shared within the CDE.
3. **Data Security & Confidentiality**: Obligations to protect sensitive assets and adhere to security rules.
4. **Electronic Data Exchange Liability**: Allocation of risks concerning data corruption, transmission delays, and software conversion discrepancies.
