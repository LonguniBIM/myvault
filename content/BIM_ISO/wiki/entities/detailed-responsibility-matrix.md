# Detailed Responsibility Matrix

## Definition
Under ISO 19650-2 clause 5.4.2, the **Detailed Responsibility Matrix** is the operational schedule that allocates responsibility for authoring, reviewing, and approving each information container or asset element to a specific [[appointed-party]] (task team), establishing the required [[level-of-information-need]] (LOIN) for each project delivery milestone.

## Key Attributes
- **Container Identifier**: Standardized naming token or discipline breakdown.
- **Responsible Task Team**: Single named organization accountable for authoring.
- **Level of Information Need**: Prescribed geometric granularity and alphanumeric properties required per stage.
- **Information Delivery Milestone**: Scheduled delivery gate aligned with client decision points.

## Standard References
- ISO 19650-2:2018 §5.4.2 (Establish the detailed responsibility matrix)
