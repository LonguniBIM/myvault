# ISO 19650-5 (Security-Minded Approach)

**ISO 19650-5:2020** (*Part 5: Security-minded approach to information management*) specifies requirements for managing sensitive information created, stored, or processed throughout the built asset lifecycle.

## Core Governance
1. **Security Triage**: Early assessment to determine whether an initiative, asset, or associated data qualifies as sensitive.
2. **Security Manager Appointment**: Designated individual responsible for security policies, risk mitigation, and breach monitoring.
3. **Security Management Plan (SMP)**: Formulates access rules, CDE isolation protocols, encryption, and incident response procedures.
4. **Breach Management**: Defined workflows to handle unauthorized access, data loss, or disclosure.
