# Mobilization Plan

## Definition
Established initially during tender response (ISO 19650-2 clause 5.3.4) and executed upon appointment (clause 5.5.1), the **Mobilization Plan** details the activities, timelines, and responsibilities required to test systems, configure hardware/software, onboard personnel, and establish CDE connections before live information generation begins.

## Core Scope
1. **Human Resources Mobilization**: Project BIM inductions, staffing confirmations, training on project information standards.
2. **Information Technology Mobilization**: Hardware procurement, software installation/version lock, CDE permission matrix setup.
3. **Workflow & Method Testing**: Testing information exchange protocols, coordinate setups, seed files, and automated clash/QA routines.
