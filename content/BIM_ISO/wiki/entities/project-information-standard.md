# Project Information Standard

The **Project Information Standard** (ISO 19650-2 §5.1.4) is a mandatory project-level document established by the [[appointing-party]] detailing the standards, conventions, and schemas to be used across all appointments.

## Core Standard Elements
1. **Exchange Formats**: Public open standards (IFC - ISO 16739, COBie, Open XML, PDF - ISO 32000) and proprietary native formats.
2. **Information Container Naming**: Structured syntax for containers (e.g., National Annex NA.2.2: `<Project>-<Originator>-<Volume>-<Level>-<Type>-<Role>-<Number>`).
3. **Object Naming**: Conventions for BIM library objects (BS 8541-1: `<Source>-<Type>-<Subtype>`).
4. **Classification System**: Standard tables (e.g. Uniclass 2015) for structuring assets and systems.
5. **Level of Information Need**: Framework defining granularity for geometric and alphanumeric data.
6. **Annotation & Symbols**: Standardized symbology across disciplines to prevent construction errors.
