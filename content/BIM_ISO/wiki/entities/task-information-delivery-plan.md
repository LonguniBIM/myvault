# Task Information Delivery Plan (TIDP)

## Definition
Under ISO 19650-2 clause 5.4.4, a **Task Information Delivery Plan (TIDP)** is authored and maintained by each individual task team ([[appointed-party]]). It sets out the detailed schedule for the production of that team's specific information containers.

## Key Contents per Container
1. **Container Identifier & Title**: Standardized container ID conforming to project naming conventions.
2. **Deliverable Format**: Native CAD/BIM format, OpenBIM IFC, PDF/A, XLSX/COBie.
3. **Level of Information Need (LOIN)**: Specific geometric and alphanumeric detail required.
4. **Milestone Dates**: Production start date, internal QA review date, and scheduled release date.
5. **Dependencies**: Precedent information containers required from other disciplines before authoring can commence.

## Standard References
- ISO 19650-2:2018 §5.4.4 (Establish the task information delivery plan(s))
