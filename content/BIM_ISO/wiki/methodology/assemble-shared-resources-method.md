# Assemble Shared Resources Method

This methodology operationalizes **ISO 19650-2 Clause 5.2.2** for assembling reference information and shared resources prior to tender release.

## Step-by-Step Procedure

### Step 1: Audit Existing Asset Information
- Identify historical drawings, surveys, point clouds, and asset registers.
- Validate data currency and intellectual property / distribution rights.

### Step 2: Prepare Standardized Templates
- Draft a [[pre-appointment-bep]] template mapped 1-to-1 to the EIR requirements.
- Draft a Responsibility Matrix template (RACI).

### Step 3: Package Supporting Materials
- Collate templates, classification guidelines, and reference models into coherent information containers.

### Step 4: Verify CDE Metadata
- Assign appropriate CDE status codes indicating reliance limitations before publication into the ITT package.
