# Establish Project Information Standard Method

This methodology operationalizes **ISO 19650-2 Clause 5.1.4** for drafting the project-wide information standards.

## Step-by-Step Procedure
1. **Specify Exchange File Formats**: Require open schemas (IFC, COBie) alongside agreed native BIM formats.
2. **Define Container Naming Convention**: Mandate strict naming fields per National Annex (Project-Originator-Volume-Level-Type-Role-Number).
3. **Define Object Naming Standard**: Apply BS 8541-1 syntax for all model elements and library objects.
4. **Select Classification Standard**: Mandate standard classification tables (e.g. Uniclass 2015).
5. **Establish Symbology & Annotation Rules**: Standardize drawing notation to eliminate ambiguity during physical execution.
