# Establish Mobilization Plan Method

## Overview
A 5-step procedure to establish the project mobilization schedule and verification gates prior to contract execution (ISO 19650-2 §5.3.4).

## Procedure

### Step 1: Define Mobilization Window & Critical Path
Establish the timeline between appointment confirmation and the first scheduled information generation date.

### Step 2: Schedule Induction & Training Modules
Program project-specific BIM inductions, standard briefings, and software upskilling sessions for all team members.

### Step 3: Plan IT & CDE Configuration Activities
Schedule CDE environment configuration, folder structure creation, user account provisioning, and security permission setup.

### Step 4: Define Method & Protocol Testing Milestones
Incorporate dry-run exchange tests (IFC coordinate testing, schema validation, test clash detection).

### Step 5: Assign Ownership & Sign-off Gateways
Assign named leads for each mobilization task and establish a formal mobilization completion review gate.

## Control Points & Pass/Fail Criteria
- **Pass**: Mobilization schedule accounts for all identified capability gaps and allows buffer time for CDE validation.
- **Fail**: Zero mobilization period allocated, forcing production to commence on day one without testing.
