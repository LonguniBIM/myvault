# Establish Project Information Requirements Method

This methodology operationalizes **ISO 19650-2 Clause 5.1.2** for formulating client decision-driven information requirements.

## Step-by-Step Procedure
1. **Review Strategic Objectives**: Review the project brief, business case, and organizational drivers (OIR).
2. **Map Key Decision Points**: Identify gateway review milestones throughout the plan of work.
3. **Formulate High-Level Questions**: Write clear, non-technical questions required to approve each gateway.
4. **Link to Information Types**: Define the necessary deliverables (models, cost schedules, certificates) required to answer each question.
