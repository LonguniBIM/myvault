# Mobilize Resources & IT Method

## Overview
A 5-step procedure for executing human resource onboarding, IT hardware/software deployment, and CDE environment setup (ISO 19650-2 §5.5.1).

## Procedure

### Step 1: Conduct Project BIM Induction Meeting
Convene mandatory induction for all authoring personnel covering EIR goals, naming standards, and CDE workflows.

### Step 2: Deploy & Version-Lock Software
Verify software build versions, CAD/BIM template deployments, and plugin installations across all participating firms.

### Step 3: Configure Project CDE & User Access Groups
Set up CDE folder hierarchies, metadata schemas, permission groups (WIP, Shared, Published), and automated notification rules.

### Step 4: Establish Distributed CDE Synchronization Links
Where task teams utilize local internal CDEs, establish verified file transfer and approval gateways to the main project CDE.

### Step 5: Execute User Acceptance Verification
Confirm every team member can log in, access project resources, and perform test check-in/check-out operations.

## Control Points & Pass/Fail Criteria
- **Pass**: 100% of authoring staff attend induction and possess active, tested CDE access prior to authoring.
- **Fail**: Teams allowed to author data using unverified software versions or unapproved cloud file sharing.
