# Overview

This wiki is a **curated knowledge base for mastering BIM information management under ISO 19650** — systematically breaking down the standard and related guidance (EIR/AIR, BEP, MIDP/TIDP, CDE workflows) into applicable project methods, and converting validated methods into deployable Claude Skills.

## How It Works

1. **Capture** — Collect standard text, guidance, EIR/BEP samples, training material, case studies, project lessons learned
2. **Classify** — Sort by topic, project stage, role, information-requirement type, authority level
3. **Analyze** — Apply the ten-question framework (see `schema.md`) to each source
4. **Map** — Link standard requirements to project documents, responsible roles, software, data, deliverables
5. **Extract** — Identify methodologies with numbered steps/control points → methodology pages
6. **Operationalize** — Convert standard language into project actions, control points, pass/fail criteria, evidence
7. **Synthesize** — Group findings by topic (information requirements, BEP, CDE, delivery planning, validation, coordination, handover)
8. **Build** — Convert validated methodologies into working Claude Skills with trigger, scope, inputs, workflow, guardrails, output format
9. **Test** — Apply Skills to real project documents/data; compare against expert or approved process
10. **Iterate** — Update knowledge base and Skills as standards, project feedback, and edge cases evolve
