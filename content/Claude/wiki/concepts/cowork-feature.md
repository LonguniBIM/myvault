# Cowork: Autonomous Multi-Step Task Execution

## Definition

**Cowork** is a Claude feature (Pro tier and above) that enables Claude to run complex, multi-step tasks autonomously over extended periods without requiring user approval at each step.

## Key Capabilities

- **Autonomous execution**: Claude executes multi-step workflows without waiting for user feedback
- **Extended duration**: Can manage long-running tasks (hours, not just minutes)
- **File integration**: Accesses local folders and data sources directly
- **Cross-tool coordination**: Synthesizes information from multiple sources (Gmail, notes, Slack, etc.)

## Pricing Availability

- **Free tier**: Not available
- **Pro ($20/month)**: Included
- **Max ($100-200/month)**: Included

## Use Cases

### 1. First-Week Experiments
- Organize file folders automatically
- Extract meeting decisions from notes
- Summarize lengthy documents

### 2. Professional Workflows
- **Negotiation preparation**: Aggregate Gmail + notes + Slack → generate strategic briefs
- **Document organization**: Auto-categorize and archive files
- **Research synthesis**: Combine multiple data sources into coherent analysis

## How It Works

1. User describes multi-step workflow
2. Claude breaks down into sub-tasks
3. Claude executes autonomously without stopping for approval
4. Generates output integrating results across sources

## Comparison to Standard Mode

| Aspect | Standard | Cowork |
|--------|----------|--------|
| Execution | Step-by-step with user waits | Autonomous, continuous |
| Duration | Minutes | Hours |
| File access | Limited | Full folder integration |
| Data sources | One at a time | Multiple simultaneous |
| User approval | Each step | Final output only |
