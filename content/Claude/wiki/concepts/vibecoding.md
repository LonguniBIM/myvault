# Vibecoding

Vibecoding is a workflow where the user describes desired outcomes in natural language while an AI coding agent implements, tests, and revises the code.

## In Claude Code

In [[ruben-hassid-2026-claude-code]], vibecoding is framed for non-coders: the user acts as project manager, [[claude-code]] acts as developer, and quality control happens through live previews, screenshots, and iterative feedback.

## Effective Habits

- Describe the end result instead of implementation steps.
- Work one deliverable at a time.
- Provide reference screenshots and files.
- Test the live output visually.
- Stop repeated error loops and request alternative approaches.
