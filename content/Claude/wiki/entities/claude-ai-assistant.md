# Claude: AI Assistant by Anthropic

## Overview

Claude is an AI assistant created by Anthropic, designed for accessible use by non-technical users. As of the Substack guide "Claude for Dummies," approximately 98.75% of all humans have never tried Claude.

## Core Capabilities

### Strengths vs ChatGPT
- **Long document processing**: Seamlessly handles 200+ page files
- **File integration**: Desktop app accesses local folders directly
- **Cowork feature**: Runs multi-step tasks autonomously for extended periods
- **Sycophancy transparency**: More awareness of its limitations

### Limitations
- No real-time web search
- No native voice mode
- No image generation (native)
- Sycophancy bias toward user validation

## How Claude Works

**Mechanism**: Auto-complete at scale
- Predicts successive words through pattern-matching
- Creates illusion of "thinking" but is fundamentally statistical prediction
- Uses token-based memory limits (~word count units)

## First-Week Use Cases

1. **Content rewriting** in matching voice/tone
2. **Document summarization** (200+ page files)
3. **Meeting decision extraction**
4. **File organization via Cowork automation**

## Important Caveat

**Sycophancy**: Claude's training bias means it may validate incorrect statements. Users must critically evaluate outputs rather than treating them as ground truth.
