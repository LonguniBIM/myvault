# Claude

## Overview

Claude is an AI assistant created by [[Anthropic]]. It's a large language model designed for knowledge work, coding, analysis, and creative tasks.

## Key Features

- **Multiple interfaces**: Chat (web), Cowork (desktop app), Code (CLI for developers)
- **Large context window**: 1,000,000+ tokens for reasoning with extensive text
- **Extended Thinking**: Internal reasoning mode for deeper analysis
- **Connectors**: Integration with Slack, Google Drive, Notion, Figma, 50+ tools
- **Artifacts**: Interactive outputs (calculators, charts, HTML tools)
- **Projects**: Persistent context folders with file memory

## Model Versions

- **Opus 4.6** (February 2026) - Most capable model for reasoning and writing
- **Sonnet** - Balanced performance and speed
- **Haiku** - Fast, lightweight model

## Pricing Tiers

- **Free** - Basic access
- **Pro** ($20/month or $17/month annually) - Required for Cowork, Projects, Plugins
- **Team** - Multi-user plans
- **Enterprise** - Custom deployments
