# Claude (overview)

Claude is Anthropic's AI assistant, available across six distinct tools and interfaces, each optimized for different workflows.

## Core Capabilities

- **1M+ token context** — Largest context window in the industry
- **Opus 4.6 model** — Latest reasoning and coding capabilities
- **Multimodal** — Text, images, documents, code
- **Extended thinking** — Deep reasoning mode for complex problems

## Interfaces

1. **[[claude-chat]]** — Web and mobile conversational interface
2. **[[claude-code]]** — IDE integration for developers
3. **[[claude-cowork]]** — Desktop app for autonomous workflows
4. **[[claude-artifacts]]** — Standalone documents and tools
5. **[[claude-connectors]]** — Slack, Drive, Notion, Excel integrations
6. **[[extended-thinking]]** — Deep reasoning mode

## Pricing & Access

- **Claude Free** — Limited usage, Haiku model
- **Claude Pro** — $20/month, Opus access, Cowork
- **Claude Team** — $30/user/month, shared workspace, audit logs
- **Claude API** — Pay-per-token via Anthropic API
