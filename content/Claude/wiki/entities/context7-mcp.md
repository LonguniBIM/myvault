# Context7 MCP Server

Free MCP server that provides Claude Code and Cursor with compressed, LLM-optimized documentation for popular libraries and frameworks.

## Problem It Solves

When you ask Claude to integrate a library by providing a URL, it has to scrape the page — unreliable and poorly formatted. Context7 pre-compresses and formats documentation so the AI digests it accurately.

## Usage

Tell Claude: *"use the latest documentation for PostHog — please use the Context7 MCP"* — Claude will pull the correct, compressed docs and implement accurately.

## Why It Matters

- More reliable than URL-based documentation feeding
- Better formatted for LLM consumption
- Always latest version
- Free
