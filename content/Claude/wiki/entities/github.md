# GitHub

GitHub is a repository hosting platform used by [[claude-code]] workflows to store code online, create repositories, and publish projects.

## Role in Claude Code Workflows

In [[ruben-hassid-2026-claude-code]], GitHub is explained to non-coders as "Google Drive for code." The recommended onboarding flow starts by creating a free GitHub account and connecting it to Claude so generated websites can be pushed online and shared.
