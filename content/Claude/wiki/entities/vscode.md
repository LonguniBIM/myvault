# VS Code

VS Code is a code editor that can host the official Claude extension and provide a faster [[claude-code]] workflow than the desktop Code tab.

## Role in Claude Code Workflows

In [[ruben-hassid-2026-claude-code]], VS Code is recommended after the first Claude Code trial because it offers better file browsing and bypass/skip permissions mode. This reduces [[permission-friction]] during longer vibecoding sessions.
