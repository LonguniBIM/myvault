# Whisper Flow

Voice dictation tool with built-in developer terminology support. Used for dictating detailed prompts to AI coding tools.

## Why Dictate Instead of Type

- Dictation produces significantly more detailed prompts in less time
- More detail = better AI steering
- Developer terms (API names, library names, technical jargon) recognized correctly
- The author dictates 90%+ of their Claude Code / Cursor prompts

## Alternatives

Other voice tools work, but Whisper Flow's developer terminology support makes it particularly well-suited for technical prompting.
