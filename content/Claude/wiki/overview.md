# Overview

This wiki is a **curated knowledge base for mastering Claude Code** — understanding its internals, using it effectively, optimizing performance, and converting documentation into deployable Skills.

## How It Works

1. **Capture** — Clip documentation, tutorials, blog posts, and repos
2. **Analyze** — Apply the six-question framework to each source
3. **Extract** — Identify methodologies with numbered steps → Skill candidates
4. **Synthesize** — Group findings by topic, compare approaches
5. **Build** — Convert validated methodologies into working SKILL.md files
6. **Deploy** — Test and deploy skills to actual Claude Code environments
