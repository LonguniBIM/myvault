# Claude Onboarding for Beginners

## Why This Matters

98.75% of people haven't tried Claude. Most beginners get frustrated by vague results or sycophancy. This skill provides the "boss mindset" needed to get value out of your new AI "employee."

## The Skill

Execute a 5-step onboarding path to graduate from simple chat to agentic workflows.

## Steps

### Phase 1: Setup (5 minutes)

1. Sign up at **claude.ai**.
2. Install the **desktop app** (Mac/Windows) to unlock file access and Cowork.

### Phase 2: The Prompting Rules

1. **Be Specific**: Vague prompts = vague output.
2. **Give Examples**: Paste your own writing; Claude learns faster from examples than rules.
3. **Say what you WANT**: Positive instructions beat negative ones.
4. **Conversation > One-shot**: Start short, add detail, and treat it like a chat.

### Phase 3: The Graduation Path

1. **Chat Mode**: Use for drafts, brainstorming, and "thinking out loud."
2. **Cowork Mode (Pro)**: Graduate here for multi-step jobs (e.g., "Analyze these 40 invoices and create a summary spreadsheet").

### Phase 4: The Fresh Start Habit

1. If Claude gets confused or the history gets too long: **Start a new chat.**
2. Don't try to fix a "broken" conversation with more messages.

### Phase 5: The "10 Things to Try"

Book 20 minutes to try these 3 high-value tasks:
- **Decision Log**: Paste meeting notes and ask for a "Decisions vs. Action Items" log.
- **Folder Cleanup**: Point Cowork to your Downloads folder and ask for a logical organization plan.
- **Pricing Analysis**: Paste a competitor's pricing page and ask for a gap analysis.

## Watch Out For

- **Trusting Agreement**: Claude might nod along even if you are wrong (sycophancy).
- **Precise Math**: It's a word machine, not a calculator (use code/spreadsheets for math).
- **Vague Requests**: Don't assume Claude is a "god" that knows what you want without detail.
