# Claude for Dummies: Getting Started Guide

## Six-Question Analysis

### 1. What problem does this document solve?
**Goal**: Introduces Claude to beginners (98.75% of humans haven't tried it yet) and explains core concepts, pricing, and practical first-use cases.

**Audience**: Non-technical users, AI newcomers, decision-makers evaluating Claude vs ChatGPT.

---

### 2. What numbered steps does the author prescribe?

#### First-Week Experiments
1. Rewrite content in matching voice/style
2. Summarize lengthy documents (200+ pages)
3. Extract meeting decisions and action items
4. Organize file folders via Cowork automation

#### Negotiation-Preparation Workflow
1. Connect Gmail inbox + Granola notes + Slack
2. Synthesize across all three data sources
3. Generate strategic negotiation drafts autonomously via Cowork
4. Refine based on Claude's outputs

---

### 3. What principles recur throughout?

**Claude's Strengths**:
- Handles long documents (200-page files seamlessly)
- Desktop app with local file access
- Cowork for autonomous multi-step execution
- Better sycophancy transparency than ChatGPT

**Claude's Limitations**:
- No real-time web search (unlike ChatGPT)
- No native voice mode
- No image generation (unlike ChatGPT)
- Sycophancy: training bias toward user validation

**Pricing matches complexity**:
- Free: Try basics, limited daily messages
- Pro ($20/mo): Cowork access, daily power use
- Max ($100-200/mo): Heavy professional use

---

### 4. What mistakes does the author warn against?

- **Sycophancy trap**: Claude may validate incorrect statements due to training bias
- **Overestimating capabilities**: Confusing pattern-matching with true reasoning
- **Overestimating autonomy**: Claude is auto-complete, not AGI
- **Ignoring comparison context**: Each tool has specific strengths/weaknesses

---

### 5. What diagnostic questions does the author pose?

- How does Claude compare to ChatGPT in specific use cases?
- What are tokens and why do they matter?
- How does Claude seem to think if it's just predicting words?
- What can I realistically accomplish in my first week?
