## Six-Question Analysis

### Q1 — What problem does this solve?

It solves the coding barrier for non-technical users. It frames "English as the new code" and provides a workflow for non-coders to build websites, dashboards, and training materials using Claude Code without ever writing a line of actual code.

### Q2 — What numbered steps does the author prescribe?

**Setup Workflow:**
1. Create a free **GitHub** account (the "Google Drive for code").
2. Connect GitHub to Claude in **Settings > Connectors**.
3. Create a project folder (e.g., "Claude-Code") and add context files like `about-me.md`.
4. (Recommended) Download **VS Code** and install the **Claude extension** to use "Skip Permissions" mode for 100x faster execution.

**Vibecoding Workflow:**
1. Start with a **screenshot** of a design you like.
2. Use a prompt template: "Create a GitHub repo named [X]. I don't know how to code. [Goal] for [Success Criteria]. [Steps]."
3. Use **Opus 4.6** and "Auto accept edits".
4. Check the live website, list problems, and have Claude fix them iteratively.
5. Create a **CLAUDE.md** file to act as the project's "brain" and memory.

### Q3 — What principles recur?

- **Vibecoding**: Building by directing an AI through natural language and visual feedback.
- **English as Code**: Describing the end result (brief) rather than implementation steps.
- **Visual QA**: Testing the live result visually since the user cannot review the underlying code.
- **Iterative Sprints**: Building one feature/page at a time rather than dumping everything into one prompt.

### Q4 — What mistakes does the author warn against?

- Trying to write code instructions (e.g., "use flexbox") instead of product goals.
- Getting bogged down by permission popups (use VS Code to bypass).
- Overloading prompts with too many features.
- Trusting the code blindly without testing the live site.
- Letting Claude spiral into an error loop (intervene if the same error appears twice).

### Q5 — What diagnostic questions does the author pose?

- What does success look like for this deliverable?
- Is this one deliverable or a bundle?
- Has Claude repeated the same error twice?
- What should be in CLAUDE.md to preserve this session's context?

### Q6 — Can the method be expressed as numbered steps?

**YES** — Skill candidate: `vibecoding-for-non-coders`.
