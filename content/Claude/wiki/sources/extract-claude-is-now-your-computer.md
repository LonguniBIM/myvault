## Six-Question Analysis

### Q1 — What problem does this solve?

It solves the problem of remote computer control and desktop automation for non-technical users. It allows users to execute complex tasks (finding freelancers, scraping ads, scheduling research) on their actual computer while they are away, using a mobile interface (Claude Dispatch).

### Q2 — What numbered steps does the author prescribe?

**Setup Process:**
1. Download Claude desktop app at `claude.ai/download`.
2. Use a **paid personal account** (Pro or Max).
3. Enable "Computer use" in Settings > Desktop app > General.
4. Grant OS permissions (Accessibility and Screen recording).
5. (Optional) Deny specific apps (like password managers) for security.
6. Open **Dispatch** in the sidebar and scan the QR code with the Claude mobile app.

**Task Execution:**
1. Keep the computer turned on and awake.
2. Open Claude app on phone > Dispatch.
3. Prompt for desktop tasks (e.g., "Go to Fiverr...").

**Scheduling:**
1. Go to **Scheduled** in the sidebar.
2. Create **New task** with name, description, and tested prompt.
3. Choose frequency and model.

### Q3 — What principles recur?

- **AI as an Employee**: Claude is treated as a junior staff member who can click, type, and navigate for you.
- **Hardware-Software Link**: The computer must be "awake" to act as the execution engine for the mobile "remote control".
- **Visual Verification**: The user can see what the computer sees through the mobile app.

### Q4 — What mistakes does the author warn against?

- Using a Business/Team account (compliance might block Computer Use features).
- Letting the computer sleep/hibernate (stops execution).
- Not denying sensitive apps (like 1Password) from Claude's view.
- Not testing a prompt in normal chat before scheduling it.

### Q5 — What diagnostic questions does the author pose?

- Is the computer "awake"?
- Am I using the right account type (Paid Personal)?
- Did I grant the necessary Accessibility/Screen recording permissions?

### Q6 — Can the method be expressed as numbered steps?

**YES** — Skill candidate: `setup-claude-computer-use`. It covers setup, remote triggering, and scheduling.
