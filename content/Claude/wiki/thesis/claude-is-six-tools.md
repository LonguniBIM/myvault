# Claude is Six Tools (thesis)

Claude is not a single product but six distinct tools, each optimized for different workflows and use cases.

## The Six Tools

1. **[[claude-chat]]** — Conversational interface for research, brainstorming, Q&A
2. **[[claude-code]]** — IDE integration for software engineering workflows
3. **[[claude-cowork]]** — Desktop app for autonomous multi-step task execution
4. **[[claude-artifacts]]** — Standalone documents and interactive tools
5. **[[claude-connectors]]** — Integrations with Slack, Drive, Notion, Excel
6. **[[extended-thinking]]** — Deep reasoning mode for complex problems

## Implications

- Users should choose the tool that matches their workflow, not force all work into one interface
- Each tool has different token economics and latency characteristics
- Mastery requires understanding when to switch between tools
