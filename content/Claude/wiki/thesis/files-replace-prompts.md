# Files Replace Prompts (thesis)

The most effective way to use Claude is not through prompts, but through structured files that encode context, preferences, and constraints.

## Core Principle

Instead of:
```
"Use a friendly tone, avoid corporate jargon, focus on practical examples..."
```

Use:
```
anti-ai-writing-style.md (loaded automatically)
```

## Key Files

- **about-me.md** — User profile, role, preferences
- **my-company.md** — Company context, stakeholders, constraints
- **DESIGN.md** — Brand system, visual guidelines
- **CLAUDE.md** — Project-specific instructions for Claude Code

## Benefits

- **Reusability** — Write once, apply to all conversations
- **Consistency** — Same context across sessions
- **Token efficiency** — Files are cached, prompts are not
- **Version control** — Track changes to context over time
