## Key Points

- Visual companion to the Expansion Model course — shows the complete decision tree in one page
- Confirms the 4-layer model: Caution → Structure → Invalidation → Execution
- Caution layer: Monday Avoid + High Impact News + News Protocol
- Structure layer: Relevant Swings → Protected Swing, Close Through, Neutral Range, Large Wick, Swing Breakout, Internal Range, External Range
- Invalidation layer: Invalidation Point → Reversal Day / Continuation Day / Invalidated Day → Relevant Level / Large Candle Wick / Respecting / Large Candle Body / Remaining Valid
- Execution layer: Profile Confirmation → 01:00 Reversal / 08:00 Reversal → 01:00 Entry / 08:00 Entry / Overnight Expansion / Large Wick
- The flow structure visually validates that Group C (Invalidation) is a complete, dedicated layer — not bolted on
